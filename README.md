## About *Dimming Light*
**Dimming Light** is a game project created with ***Unreal Engine (v5.4.4)*** and ***C++***, with the original purpose of practicing my development and programming skills, as well as showing them to both my teachers and colleagues. 

While developing it, I found myself experimenting with the engine and learning a lot. Since I had more experience in Unity projects, I found the development of this project more of a learning source, than an actual project, which made me spend lots of hours testing, coding, thinking of new solutions and challenges, getting some frustration now and then... But at the end (the first time I showed it, yet here I am still developing it) I got a demo I really liked and I felt proud of.

However, as I said, this project is nothing but a tool for me to keep growing as a developer, so if you want to experience it, keep in mind there might be some bugs, or some things that could yet be improved.

For now, that's it. Enjoy!

## Getting ready
1. First things first, in order to play the game or experiment with the project, you should [clone the repo from GitHub](https://github.com/BitterBaitBite/DimmingLight). There you can check the overall project.
2. Once you get the project, get sure you have the correct version of *Unreal Engine* installed: **v5.4.4**
3. Open the *.uproject* file inside the project folder. This should open the project in *Unreal Engine* editor.

### Optional
4. In the *Unreal Engine* editor, click on the menu "*Tools*" and then click on the option to generate the project's source code (depending on your preferred source code editor).
5. Within the same menu, click to open your preferred source code editor.
6. Enjoy the code!

# DIMMING LIGHT
Enjoy a **rogue-like* in a dark environment, which will make you crawl through a **dungeon** looking to survive, **loot treasures**, **kill enemies**, and find the exit gate... All of it while **your light** source keeps **fading** every second!
